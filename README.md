ОПИСАНИЕ ПРОГРАММЫ
------------------------------------------------
Программа для автоматизации работы регистратуры поликлиники.
Позволяет:
- Вести учёт пациентов (добавление, поиск, редактирование)
- Просматривать список врачей
- Записывать пациентов на приём
- Просматривать и отменять записи

ТРЕБОВАНИЯ К СИСТЕМЕ
------------------------------------------------
- Операционная система: Linux (или любая с Python 3)
- Python версии 3.6 или выше
- Библиотека tkinter (обычно уже установлена)

УСТАНОВКА НЕОБХОДИМЫХ КОМПОНЕНТОВ
------------------------------------------------
Если Python не установлен:
    sudo apt update
    sudo apt install python3

Если tkinter не установлен (ошибка "No module named 'tkinter'"):
    sudo apt install python3-tk

ЗАПУСК ПРОГРАММЫ
------------------------------------------------
1. Откройте терминал
2. Перейдите в папку с программой:
   cd /путь/к/папке/clinic_registration
3. Запустите программу:
   python3 main.py

СТРУКТУРА ПРОЕКТА
------------------------------------------------
- main.py         - главный файл для запуска
- database.py     - работа с базой данных SQLite
- gui.py          - графический интерфейс
- clinic.db       - файл базы данных (создаётся автоматически)
- README.txt      - этот файл с инструкцией

БАЗА ДАННЫХ
------------------------------------------------
- Используется SQLite - лёгкая встраиваемая БД
- Все данные хранятся в одном файле clinic.db
- При первом запуске создаются таблицы и добавляются 5 врачей
- Номер полиса пациента должен быть уникальным

КАК ПОЛЬЗОВАТЬСЯ ПРОГРАММОЙ
------------------------------------------------

ВКЛАДКА "ПАЦИЕНТЫ":
1. Нажмите "Добавить пациента"
2. Заполните форму (ФИО и номер полиса обязательны)
3. Нажмите "Сохранить"
4. Для поиска введите текст в поле "Поиск"

ВКЛАДКА "ВРАЧИ":
- Просто просмотр списка врачей (заполнен автоматически)

ВКЛАДКА "НОВАЯ ЗАПИСЬ":
1. Введите фамилию пациента в поле поиска (минимум 2 буквы)
2. Выберите пациента из списка
3. Выберите врача из выпадающего списка
4. Укажите дату в формате ГГГГ-ММ-ДД (например, 2026-02-20)
5. Нажмите "Показать свободное время"
6. Выберите время из списка
7. Нажмите "Записать на приём"

ВКЛАДКА "ВСЕ ЗАПИСИ":
- Просмотр всех созданных записей
- Выберите запись и нажмите "Отменить" для отмены

ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
------------------------------------------------

Ошибка "No module named 'tkinter'":
    sudo apt install python3-tk

Ошибка "file is not a database":
    Удалите файл clinic.db и запустите программу заново:
    rm clinic.db
    python3 main.py

Ошибка прав доступа:
    chmod 755 /путь/к/папке/clinic_registration/

ДЛЯ РАЗРАБОТЧИКА
------------------------------------------------
- Все функции работы с БД в database.py
- Все функции интерфейса в gui.py
- Для добавления новых полей в БД измените SQL в init_db()
- Для изменения времени работы измените диапазон в get_free_time()
