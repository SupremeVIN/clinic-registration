ОПИСАНИЕ ПРОГРАММЫ
------------------------------------------------
Программа для автоматизации работы регистратуры поликлиники с фокусом на безопасность данных.

Возможности:
- Учёт пациентов (добавление, поиск, редактирование, удаление)
- Просмотр списка врачей
- Запись пациентов на приём с проверкой свободного времени
- Просмотр и отмена записей
- Статистика работы поликлиники
- Журнал аудита всех действий

СИСТЕМА БЕЗОПАСНОСТИ (v2.0)
------------------------------------------------
Защита от SQL-инъекций:
- Все запросы параметризованы
- Нет конкатенации строк в запросах

Валидация данных:
- ФИО: только буквы, пробелы, дефисы, точки (2-200 символов)
- Номер полиса: цифры, дефисы, пробелы (10-20 символов)
- Телефон: цифры, +, -, пробелы, скобки (до 20 символов)
- Дата: строгий формат ГГГГ-ММ-ДД + проверка корректности

Логирование и аудит:
- Все действия записываются в audit.log
- Номера полисов хешируются в логах
- Время, действие, пользователь

Резервное копирование:
- Автоматически при запуске
- Автоматически перед опасными операциями
- Ручное создание через меню

Проверка целостности:
- Диагностика БД при запуске
- Восстановление повреждённых файлов

ТРЕБОВАНИЯ К СИСТЕМЕ
------------------------------------------------
- ОС: Linux, Windows, macOS
- Python 3.6 или выше
- Библиотека tkinter

УСТАНОВКА
------------------------------------------------
Linux (Ubuntu/Debian):
sudo apt update
sudo apt install python3 python3-tk
chmod +x setup_linux.sh
./setup_linux.sh

Linux (Fedora):
sudo dnf install python3 python3-tkinter

Linux (Arch):
sudo pacman -S python tk

Windows:
1. Установите Python с python.org (отметьте "Add Python to PATH")
2. Запустите setup_windows.bat

ЗАПУСК ПРОГРАММЫ
------------------------------------------------
Ручной запуск:
cd /путь/к/папке
python3 main.py

После установки:
- Linux: ярлык на рабочем столе "поликлиника.desktop"
- Windows: ярлык на рабочем столе "Поликлиника"

РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ
------------------------------------------------

ВКЛАДКА "ПАЦИЕНТЫ"
- Добавление: кнопка "Добавить пациента" → заполнить форму
- Поиск: введите текст в поле поиска (от 2 символов)
- Редактирование: выбрать пациента → "Редактировать"
- Удаление: выбрать пациента → "Удалить" (запрещено если есть будущие записи)

ВКЛАДКА "ВРАЧИ"
- Просмотр списка врачей (режим только чтение)
- При первом запуске добавляются 5 врачей

ВКЛАДКА "НОВАЯ ЗАПИСЬ"
1. Введите фамилию пациента (минимум 2 буквы)
2. Выберите пациента из списка
3. Выберите врача
4. Введите дату (ГГГГ-ММ-ДД)
5. Нажмите "Показать свободное время"
6. Выберите время
7. Нажмите "Записать на приём"

ВКЛАДКА "ВСЕ ЗАПИСИ"
- Просмотр всех записей
- Отмена: выбрать запись → "Отменить запись"
- Удаление старых: "Удалить старые записи" (старше 30 дней)

ВКЛАДКА "СТАТИСТИКА"
- Количество пациентов, врачей, записей
- Размер базы данных
- Дата последнего бэкапа
- Статус безопасности

МЕНЮ "БЕЗОПАСНОСТЬ"
- Показать журнал аудита
- Проверить целостность БД
- Статистика безопасности

МЕНЮ "ФАЙЛ"
- Обновить всё
- Очистить кэш БД (VACUUM)
- Создать резервную копию
- Выход

ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
------------------------------------------------

Ошибка "No module named 'tkinter'":
Linux: sudo apt install python3-tk
Windows: переустановите Python с опцией tcl/tk

Ошибка "file is not a database":
rm clinic.db
python3 main.py

Ошибка прав доступа (Linux):
chmod +x main.py
chmod 755 /путь/к/папке/

Не удаётся добавить пациента:
- ФИО минимум 2 символа
- Номер полиса уникален
- Номер полиса 10-20 символов
- Номер полиса: только цифры, дефисы, пробелы

Не получается записаться:
- Выбран ли пациент
- Выбран ли врач
- Дата не в прошлом
- Время выбрано из списка
- Есть свободные слоты

ДЛЯ РАЗРАБОТЧИКА
------------------------------------------------

Основные модули:
database.py - работа с БД, валидация, логирование, безопасность
gui.py - графический интерфейс, все вкладки и диалоги
main.py - точка входа, проверка окружения

Расширение функционала:
- Новые поля в БД: изменить SQL в init_db()
- Изменение времени работы: изменить диапазон в get_free_time()
- Новые проверки: добавить функцию validate_* в database.py

Структура БД:

Таблица patients:
id INTEGER PRIMARY KEY
full_name TEXT NOT NULL
birth_date TEXT
phone TEXT
policy_number TEXT UNIQUE
created_at TIMESTAMP

Таблица doctors:
id INTEGER PRIMARY KEY
full_name TEXT NOT NULL
specialty TEXT
room_number TEXT
created_at TIMESTAMP

Таблица appointments:
id INTEGER PRIMARY KEY
patient_id INTEGER (FOREIGN KEY)
doctor_id INTEGER (FOREIGN KEY)
date TEXT NOT NULL
time TEXT NOT NULL
status TEXT DEFAULT 'запланирован'
cancelled_at TIMESTAMP
cancel_reason TEXT
created_at TIMESTAMP
UNIQUE(doctor_id, date, time)
